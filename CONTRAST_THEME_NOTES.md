# Contrast palette update

The original identity remains champagne `#EFE1CE`, rose gold `#B9857C`, black cherry `#721D35`, dark cherry `#42121F`, and near black `#1C0B12`.

Additional accents make source comparisons and controls distinguishable:

- Cyan `#45D7D1` — source 1 / primary charts / active navigation
- Gold `#F4CB72` — source 2 / important actions / highlights
- Lavender `#B7A2FF` — source 3
- Coral `#FF9388` — source 4 / comparative period
- Mint `#88E0AC` — source 5 / positive change

Each chart uses source IDs sorted deterministically, so a source keeps a consistent colour within each visualisation. Source names remain visible in legends (colour is not the only cue).

This changes CSS and Plotly presentation only; no question planning, uploaded data, cost calculations, evidence, or API logic was modified.
